**科研选题报告评审操作说明**

评审流程把案例要求、同一输入下的两份报告，以及评审者的逐项判断保存在一起，用来发现开发修改的收益和退步。程序检查记录是否完整、引用位置是否存在，并根据人工标签归纳结果；它不自行判断论文结论或创新价值。

先整理一份案例规则，格式与 examples/review-criteria.json 相同。每例至少包含三条 criteria、一条 failures，以及可选的 ambiguities。id 必须与输入案例相同。not_applicable 可将某个评价维度映射到理由，必须在规则快照创建前确定。现有示例是公开文献构造草案。

在生成回答之前运行 review-plan。它只将所选案例的规则与输入哈希写入一个新文件，不会将规则注入生成提示。随后使用同一输入完成两次生成或导入。两方的模型、材料、预算和输出要求应尽量一致；当前程序强制检查相同输入，其余比较条件仍需组织者核查。

运行 blind 并指定 --plan 后，reviewer 文件夹包含：

| 文件 | 用途 |
|---|---|
| A.html、B.html | 阅读两份匿名报告 |
| A.json、B.json | 定位评审对应的输出字段 |
| input.json | 查看双方共同使用的研究材料 |
| criteria.json | 查看规则快照、具体要求及预先排除的维度 |
| rating.json | 填写本评审者的判断 |
| review-instructions.txt | 查阅填写规则 |
| packet.json | 核对材料哈希、规则版本与创建时间关系 |

组织者保留上一级 organizer-mapping.json。评审者应分别得到材料副本，不查看他人的评语；每人的提交结果保存为独立文件。若知道系统身份或已看过他人的评审，在 reviewer 字段中如实标注。

rating.json 的 A、B 各包含六个 dimensions、逐项 required_findings、逐个 candidates 和 severe_errors。每项判断使用以下结构：

```json
{
  "label": "partial",
  "rationale": "说明了结论，但没有解释这项证据如何支持它。",
  "output_pointers": ["/findings/0/statement"],
  "sources": [{"source_id": "输入中的论文ID", "locator": "第2节，第3页"}]
}
```

output_pointers 是对应 A.json 或 B.json 中的 JSON Pointer。`/candidates/0/first_test/baseline` 指向第一个候选的实验基线；`""` 指向全文，可用于说明应有内容缺失。程序会拒绝不存在的位置。sources 可以为空，例如只评价工期约束；填写文献依据时，ID 必须来自共同输入，并提供原文位置。位置存在不代表评审理由成立。

labels 的使用口径：

| 标签 | 含义 |
|---|---|
| pass | 满足规则，理由及依据充分 |
| partial | 部分满足，仍有需要修改之处 |
| fail | 违反要求 |
| unknown | 材料或评审能力不足以判断 |
| not_applicable | 规则快照已预先排除此维度 |

不要只评价最好的候选。每个候选都需要填写自己的判断；必要时使用其输出路径说明问题。发现重大错误时，在 severe_errors 中记录 description、output_pointers、sources。未发现时保留空数组，而不是省略字段。

最后填写 preference：A、B、tie、neither 或 unknown，并写 reason。先判断证据和硬约束，再比较对下一步行动的帮助。偏好与合格状态分别保存：偏好一份回答不意味着它已合格。

review-submit 会拒绝空白模板、材料变更、错误位置、遗漏候选及事后添加的“不适用”。所有适用要求通过且没有重大错误时，结果为 pass；存在失败或重大错误时为 fail；否则有 unknown 时为 unresolved，有 partial 时为 needs_revision。

提交文件保留全部原始判断与哈希，不覆盖已有文件，也不修改原运行中的科研质量状态。每位评审者的一次 pass 只是该评审者对该输出的意见，不能解释成领域共识。规则创建时间早于运行的标志来自本地记录，不能证明外部预注册、模型训练数据独立或评审真正盲态。

报告结果时逐例列出错误、分歧和实际成本，不把重复运行、多个候选或多位评审者当成独立案例。构造案例、真实案例和保留案例分别统计。当前功能检查不能证明工具已改善真实科研选题。
